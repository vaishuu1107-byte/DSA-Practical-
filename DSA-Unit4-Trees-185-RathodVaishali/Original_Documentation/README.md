# Original Documentation

This folder contains the original implementation of the Menu-Driven Binary Search Tree (BST) program.

## Files

- `Problem_Statement.md` – Contains the original problem statement.
- `Algorithm.md` – Contains the step-by-step algorithm.
- `main.cpp` – Contains the C++ source code.
- `Flowchart.png` – Contains the program flowchart.
- `Output.pdf` – Contains the program output.
- `Report.pdf` – Contains the project report.

## Operations

The program supports:
1. Insertion
2. Searching
3. Deletion
4. Inorder Traversal
5. Preorder Traversal
6. Postorder Traversal
7. Exit
