# Algorithm

1. Start the program.
2. Create an empty Binary Search Tree (BST).
3. Display the menu with the following operations:
   - Insert a node
   - Search for a node
   - Delete a node
   - Inorder traversal
   - Preorder traversal
   - Postorder traversal
   - Exit
4. Accept the user's choice.
5. Perform the selected operation:
   - **Insertion:** Insert the given value into its correct position in the BST.
   - **Searching:** Search for the given value and display whether it exists.
   - **Deletion:** Delete the specified value while maintaining BST properties.
   - **Inorder Traversal:** Display nodes in left-root-right order.
   - **Preorder Traversal:** Display nodes in root-left-right order.
   - **Postorder Traversal:** Display nodes in left-right-root order.
6. Repeat the menu until the user selects Exit.
7. Stop the program.
